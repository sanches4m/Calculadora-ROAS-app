# 🛒 E-commerce Profit & Pricing Calculator (Streamlit App)

## 📌 Sobre o Projeto
Aplicativo web interativo desenvolvido em Python para resolver um dos maiores desafios da gestão de e-commerce: a precificação exata e o cálculo de rentabilidade em múltiplos canais de venda. 

Criado para otimizar a inteligência de negócios e o controle financeiro (utilizado na prática pelas operações de lojas de e-commerce), este app substitui planilhas complexas e fragmentadas por uma interface unificada. Ele processa automaticamente margens de lucro, ROAS (Retorno sobre Investimento em Anúncios), alíquotas e taxas específicas de diferentes plataformas.

## ⚙️ Funcionalidades Principais
* **Simulador Multi-Plataforma:** Algoritmos de precificação ajustados dinamicamente para as regras de comissionamento e frete da **Shopee, Mercado Livre, Shein, Amazon e Magalu**.
* **Precificação Inteligente (Markup/Margem):** Cálculo reverso para encontrar o preço ideal de venda com base no custo do produto, impostos e margem de lucro líquido desejada.
* **Análise de ROAS e Tráfego Pago:** Calculadora integrada para mensurar o ponto de equilíbrio (break-even) e a viabilidade de campanhas de marketing digital.
* **Gestão de Descontos:** Simulação instantânea do impacto financeiro ao aplicar cupons promocionais ou participar de campanhas dos marketplaces.

## 🛠️ Tecnologias Utilizadas
* **Python:** Desenvolvimento da lógica de negócios, cálculos financeiros e engenharia de software.
* **Streamlit:** Framework utilizado para a construção da interface web (Front-end) de forma ágil, transformando scripts de dados em um aplicativo interativo.

## 📈 Impacto para o Negócio
* **Proteção de Margem (Loss Prevention):** Elimina prejuízos ocultos causados por taxas de marketplace mal calculadas ou esquecidas.
* **Tomada de Decisão Ágil:** Permite que a equipe ajuste preços e estratégias de marketing em segundos, respondendo rapidamente à concorrência.
* **Escalabilidade:** A arquitetura em código (ao invés de planilhas) permite a fácil manutenção e rápida adição de novos marketplaces à medida que o negócio expande.

## 🚀 Como Executar o Projeto Localmente
1. Clone este repositório: `git clone https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git`
2. Certifique-se de ter o Python instalado em sua máquina.
3. Instale a biblioteca do Streamlit executando no terminal: `pip install streamlit`
4. Execute a aplicação com o comando: `streamlit run nome_do_seu_arquivo.py`
5. O aplicativo será aberto automaticamente no seu navegador padrão.
